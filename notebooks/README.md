# Notebooks

This folder is for runnable teaching notebooks linked from the PreTeXt book.

- R / Posit Cloud: .Rmd or Quarto notebooks.
- Python / Google Colab: .ipynb notebooks.
- Keep each notebook focused on one worked example or concept.
- Prefer cloud-readable data URLs so notebooks do not depend on a local machine.

The first worked example is the espresso multiple-regression case study.
